## 4. 架構重點（改之前要懂）

**單一權威寫入者（UI state 所有權）**：所有設定都寫進 `$cfg`（hashtable），改完呼叫 **`Apply-Settings`**，它負責：
大小 → 透明度 → 置頂 → 顯示開關 → `Apply-Theme` → `Apply-Rim` → `Apply-Frame` → 滑鼠穿透樣式 → `Save-Cfg`。
**不要在別處直接改視窗屬性**；要改行為就改 `$cfg` 再 `Apply-Settings`。

- **透明度有兩個來源**：基本透明度（滾輪／選單，`$cfg.opacity`）與「游標移上去」的暫時淡化（`$script:hovering`）。
  兩者只在 `Apply-Opacity` 合成：`hovering` 時取 `min(基本, hoverOpacity)`。滾輪調整時會暫停淡化 2 秒（`suppressUntil`），不然看不到調整結果。
- **游標偵測用 100ms 輪詢**（`Test-Hover`，把螢幕座標轉成視窗座標、判斷是否在圓內），不用 MouseEnter：
  因為滑鼠穿透模式下視窗根本收不到滑鼠事件。
- **右鍵穿透**：`rightMenu=false` 時，右鍵放開會暫時加上 `WS_EX_TRANSPARENT`，用 `mouse_event` 補送一次右鍵給底下視窗，600ms 後還原樣式。`Ctrl+右鍵`永遠叫出時鐘選單。
- **選單**是 WinForms `ContextMenuStrip`，視窗右鍵與 `NotifyIcon`（系統匣）共用同一份。這是滑鼠穿透鎖定後唯一的解除入口，**不要拿掉系統匣圖示**。
- **置頂**：`Topmost` + 每 20 秒 `SetWindowPos(HWND_TOPMOST)` 重新宣告（對抗 ClocX 時期「有時被壓到下面」）。
- **材質框**：`DcTex.Make(kind, 400)` 以 400x400 像素生成（金屬＝環形拉絲＋反光；木質＝環形年輪），轉 `ImageBrush` 當邊框描邊。
  貼圖座標用 Absolute viewport，偏移量是 `100 - 邊框半徑`（描邊的筆刷原點是橢圓幾何左上角）；改邊框半徑要同步（`Apply-Frame` 已處理）。
- **刻度**從半徑 87 起（內縮 2），避免貼在邊框內緣看起來像梯子。
- 日期使用民國年（西元 − 1911），**不寫「民國」兩字**（使用者明確要求）。日期字級依格式不同（16／14／14），**不要放大**：
  18 以上會擠到 10 與 2 兩個數字。

## 5. 地雷區（翻車史，務必遵守）

1. **絕對不要在 Claude Code 裡用 `SendKeys`／`keybd_event` 送鍵盤事件（尤其 Esc）。** 它送給前景視窗＝跑 Claude Code 的終端機本身，會打斷 session
   （2026-10-16 實際發生兩次）。已寫進 vault `ai/lessons/通用.md`。要收彈出選單就別收，或讓程式自己關。
2. **不要反覆 `Stop-Process -Force` 帶系統匣圖示的程式。** 強殺不會移除圖示，會累積成滿屏殘影（這次累積約 130 個）。
   清法：點 `^` 開隱藏圖示區，滑鼠掃過整個區域；**不要重啟 Explorer**（不處理 TaskbarCreated 的舊程式圖示會跟著不見）。
3. **`.ps1` 必須是 UTF-8 with BOM**，否則 Windows PowerShell 5.1 會把中文選單讀成亂碼／語法錯。用 Python 寫檔請 `encoding='utf-8-sig'`；
   用 Write 工具建檔後要補 BOM。改完先跑 `[System.Management.Automation.Language.Parser]::ParseFile` 檢查語法。
4. 時鐘開著時 **`-Reset` 無效**（Reset 在單一執行個體檢查之前就刪設定檔，但執行中的程式下一次存檔又會寫回去）。要重設：先結束，再 `desk-clock.bat -Reset`。
5. **使用者的設定檔是真實資料**。測試要改設定時，先備份 `%APPDATA%\desk-clock\settings.json`，測完還原並重啟時鐘（2026-10-16 做法：備份到暫存區、測完寫回）。
6. **trinkets 是公開 repo 且有 GitHub Pages**（`yjlhuang.github.io/trinkets`）。截圖預覽圖的背景是使用者螢幕上的視窗內容，**不可 commit／push**
   （已用 `.gitignore` 擋掉 `*-preview.png`）。要放預覽圖需先在純色背景重拍。
7. 搬動資料夾後排程路徑會失效 → 重跑 `install-startup.ps1`。
8. Add-Type 的 C# 類型在同一個 PowerShell session 內不能重定義；測試腳本每次都要用新行程。
9. 驗證桌面視窗用 `BitBlt + CAPTUREBLT(0x40000000)` 截圖；**一般 `CopyFromScreen` 抓不到分層（透明）視窗**。
   截圖前要把游標移開，否則會觸發游標淡化。

## 7. 與 wool-monitor 的關係

`Doe projects\wool-monitor\floating-widget.ps1` 是同類做法（WPF 無邊框透明置頂視窗、背景啟動 bat）。
Desk Clock **只借概念，沒複製程式碼**：該專案載入 WebView2 與 node 伺服器，這裡全部不要；
DPI 宣告（`SetProcessDPIAware`）、透明視窗的限制等認知來自它的註解。兩者互不依賴。
