# Desk Clock 使用指南（小白版）

一個放在桌面右上角的指針時鐘：半透明、永遠浮在最上面、可以拖來拖去。
取代原本的 ClocX，開機會自己出現。

## 一、平常怎麼用

| 想做的事 | 怎麼做 |
|---|---|
| 移動時鐘 | 對著時鐘**按住左鍵拖曳** |
| 調透明度 | 游標放在時鐘上，**滾輪**往上／往下 |
| 調大小 | 按住 **Ctrl**，再滾滑鼠滾輪 |
| 叫出設定選單 | 對著時鐘按**右鍵**（或對右下角的小時鐘圖示按右鍵） |
| 時鐘跑掉／不見了 | 雙擊右下角的小時鐘圖示，會回到右上角 |
| 關掉時鐘 | 右鍵選單最底下的「**結束**」 |

游標移到時鐘上時，時鐘會**自動變得更透明**，方便你看到後面的東西；移開就恢復。

## 二、右鍵選單裡有什麼

- **永遠置頂**：打勾＝永遠浮在其他視窗上面。
- **滑鼠穿透（鎖定）**：打勾＝滑鼠完全碰不到時鐘，點下去都點到後面的東西（時鐘只能看、不能拖）。
- **停用時鐘右鍵選單**：打勾＝對著時鐘按右鍵時，會直接叫出**後面的選單**（例如桌面的右鍵選單），而不是時鐘的選單。
- **配色**：11 種（經典藍、午夜黑、深海藍、玫瑰金、森林綠、復古棕、金屬銀、日落橘、薰衣草、薄荷冰、純黑白）。
- **邊框**：無邊框／細邊／標準／粗邊／雙線。
- **邊框材質（金屬/木質）**：純色、鉻銀、金、古銅、槍灰、胡桃木、橡木、櫻桃木。
- **日期格式**：`115/10/16`、`115年10月16日`、`10月16日 週五`（日期用民國年）。
- **顯示日期、顯示 AM/PM**：想關就取消打勾。
- **透明度、移上去時的透明度、游標移上去變透明、大小**：都可以直接選數字。
- **回到右上角**、**結束**。

## 三、最常見的狀況：我把它設成「穿透」，現在點不到了怎麼辦？

這是設計上的結果，不是壞掉。解除方法：

1. 看螢幕右下角，點 **`^`**（顯示隱藏的圖示）。
2. 找到**一個小小的時鐘圖示**，對它按**右鍵**。這份選單跟時鐘上的右鍵選單一模一樣。
3. 把「**滑鼠穿透**」的勾取消，或把「**停用時鐘右鍵選單**」的勾取消。

小提示：
- 如果只是勾了「停用時鐘右鍵選單」（但沒勾滑鼠穿透），可以不用去右下角：對著時鐘按 **Ctrl＋右鍵**，一樣會叫出時鐘的選單。
- 如果勾了「滑鼠穿透」，**Ctrl＋右鍵沒有用**（因為滑鼠根本碰不到時鐘），一定要從右下角的小圖示。

## 四、開機會自動出現

登入 Windows 後大約 **20 秒**，時鐘會自己出現（刻意延遲，是為了等桌面準備好，不然有時會被蓋住）。
想取消自動啟動：在資料夾裡打開 PowerShell，輸入

```
powershell -ExecutionPolicy Bypass -File install-startup.ps1 -Remove
```

## 五、出事了怎麼辦

| 狀況 | 做法 |
|---|---|
| 時鐘不見了 | 先看右下角（含 `^` 裡面）有沒有小時鐘圖示。有：雙擊圖示。沒有：雙擊資料夾裡的 `desk-clock.bat` 重新開 |
| 右下角冒出很多重複的小時鐘圖示 | 殘影，不是真的有那麼多個時鐘。把滑鼠在那些圖示上掃過去就會消失 |
| 想把所有設定還原成預設 | 先「結束」時鐘，再在資料夾裡打開 PowerShell 輸入 `.\desk-clock.bat -Reset`（注意：時鐘開著的時候做沒有用） |
| 時鐘被別的視窗蓋住 | 通常 20 秒內會自己回到最上面；急的話雙擊右下角圖示 |
| 開機後完全沒出現 | 打開 `%APPDATA%\desk-clock\error.log`（有錯誤才會有這個檔），把內容貼給 AI |
