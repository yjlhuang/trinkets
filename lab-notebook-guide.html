自然科學實驗筆記・教師使用手冊

學生負責思考與記錄，工具只負責整理與呈現

這個工具讓學生用自己的照片、文字和數據，一步步留下實驗過程，最後整理成一份可以閱讀、保存、列印的筆記。它不會幫學生寫任何內容。這份手冊說明怎麼帶學生用，以及怎麼用「老師檢視」和學生討論。

打開工具五分鐘上手

實驗前

約 10 分鐘
  • 開一份新筆記
  • 寫下基本資料：題目、組別、目的
  • 用自己的話寫想探究的問題

實驗中

每次觀察後 5 分鐘
  • 在過程紀錄新增一筆
  • 拍照，並寫一句照片說明
  • 當下記下意外和問題

實驗後

約 20–30 分鐘
  • 填數據與觀察
  • 挑有想法的題目寫反思
  • 按整理我的實驗筆記，交 PDF 和備份檔

五分鐘上手：先看示範，再自己試一筆

  1. 打開工具。第一次打開時會自動載入示範資料「植物生長觀察」：一組學生比較綠豆在窗邊和櫃子裡的生長情形，共有三筆不同日期的觀察。
  2. 依序點上方分頁：基本資料 → 過程紀錄 → 數據與觀察 → 反思，看看學生要填哪些東西。
  3. 按右上角「整理我的實驗筆記」。藍色手寫字是學生的原文，黑色印刷字是工具加的標題。學生沒寫的地方會標示「（未填寫）」，工具不會補。
  4. 切換到「我的原始紀錄」，可以看到學生依寫下順序留下的內容，以及每筆是什麼時候寫的、改過幾次。
  5. 打開「備份與更多 → 老師檢視」，看學習歷程時間軸長什麼樣子。
  6. 試完後按「清空示範，開始我的筆記」，就能從空白開始。

課堂流程：記錄要在當下，整理可以留到最後

最重要的習慣是做完觀察就馬上記。事後補記也可以，但老師檢視會顯示「觀察後幾天才寫下」，這正好可以拿來和學生聊記錄的習慣。

階段學生做什麼老師可以做什麼
實驗前建立筆記，寫實驗目的和想探究的問題。寫不出來可以先空著。巡視時問：「你的問題可以用這個實驗回答嗎？」不必要求一次寫完整。
實驗中每次觀察新增一筆：做了什麼、看到什麼、遇到什麼問題，再拍照。提醒學生照片要寫說明。只有照片、沒有文字的紀錄，工具會在整理前提醒。
數據整理自己決定數據表的欄位名稱，輸入測量結果。欄位名稱也是學生的思考，不需要統一格式。
反思五個開放題挑有想法的寫，一句話也可以。不要求每題都答，寫得真比寫得滿重要。
整理與繳交按「整理我的實驗筆記」，匯出 PDF，並下載備份檔。收 PDF 看成果，收備份檔看過程（見下一節）。

怎麼跟學生介紹：說清楚「這是你的紀錄」

第一次使用時，建議花兩分鐘講清楚三件事：內容是誰寫的、資料存在哪裡、老師會看到什麼。可以參考這段說法：

給學生的說明（可以照自己的語氣改）這個工具不會幫你寫報告。你寫什麼，它就整理什麼；你沒寫的，它會標示「未填寫」。
資料存在你現在用的這個瀏覽器裡，換電腦就看不到，所以每次做完都要下載備份檔。
老師收到備份檔後，會看到你什麼時候寫了什麼、改了什麼。這不是要抓錯，是想了解你的想法是怎麼變化的。

最後一點特別重要：事先告訴學生有修改紀錄，老師檢視才會被當成討論的工具，而不是監控。

收作業：PDF 看成果，備份檔看過程

檔案怎麼產生適合用來
PDF「整理我的實驗筆記」頁面，按「匯出 PDF」閱讀、批改、放進學習歷程檔案。如果 PDF 匯出失敗，改按「下載列印版」，再用瀏覽器列印成 PDF。
備份檔（.json）「備份與更多 → 下載 JSON 備份檔」用「老師檢視」看學習歷程；學生換電腦時也能用它還原。

建議的檔名規則

工具會自動以實驗名稱和日期命名。全班一起交時，可以請學生改成班級-組別-實驗名稱.json，例如 205-第3組-綠豆生長.json，老師開啟時比較好認。

收檔方式

用學校習慣的平台即可，例如 Google Classroom、雲端硬碟資料夾或學習平台的作業區。工具本身沒有伺服器，不會自動收件。

老師檢視：用歷程找到對話的切入點

從工具的「備份與更多 → 老師檢視：學習歷程時間軸」進入。按「開啟學生備份檔」，可以一次選好幾份，再用下拉選單切換。這些檔案只拿來看，不會存進電腦，也不會影響這台電腦上原本的筆記。

三種檢視

  • 歷程時間軸：學生每天做了哪些事。修改過的內容可以展開，左右對照修改前和修改後的文字。
  • 整理後筆記：學生最後交出的版本。
  • 原始紀錄：學生依寫下順序輸入的內容，沒有經過排版。

「可以聊聊的地方」怎麼用

工具會列出幾種值得注意的情況。它們不是缺點清單，而是提問的起點：

工具看到的可以這樣問
觀察後隔了幾天才寫下那天你有先記在別的地方嗎？隔幾天再寫，有沒有哪裡記不清楚？
只有照片，沒有文字這張照片裡，你最想讓別人注意到什麼？
修改過「觀察結果」你後來為什麼改？是重新量了，還是想法變了？
改寫過「想探究的問題」一開始的問題和現在的差在哪裡？是什麼讓你改的？
記下了問題或意外如果重做，你會怎麼處理這個問題？這會影響你的結論嗎？
歷程紀錄是參考，不是證據備份檔是普通的文字檔，懂一點技術的人可以修改。請把時間軸當作了解學生學習過程的線索，搭配課堂觀察和對話一起判斷，不建議用來評分或認定作弊。

工具刻意不做的事

這些限制是設計時刻意保留的，目的是讓學生把力氣花在思考和記錄上：

  • 不會代寫或改寫。整理後的筆記一字不改保留學生原文，只調整順序、加上標題。
  • 不會補資料。沒填的地方標示「未填寫」，不會用推測補上。
  • 不會強迫填完。除了紀錄日期，其他欄位都可以空著，整理前只會溫和提醒。
  • 不會評分。排版好看不代表學習品質好，工具也不判斷內容對錯。
  • 不連網路上的 AI。不需要帳號、不需要 API Key，學生資料不會上傳。

使用前的注意事項

資料只存在學生的瀏覽器

換電腦、換瀏覽器、使用無痕視窗或清除瀏覽紀錄，資料都會不見。請養成每次做完就下載備份的習慣。

共用電腦要清空

電腦教室如果多人共用同一個瀏覽器，下一位使用者會看到上一位的筆記。請學生做完後先下載備份，再按「備份與更多 → 開始一份新的筆記」清空。

照片隱私

照片會放在備份檔和 PDF 裡。提醒學生拍實驗器材就好，避免拍到同學的臉或個人資料。

學校網路可能擋外部資源

工具會從網路載入手寫字型和產生 PDF 的元件。如果學校網路擋住，字型會變成一般字體，PDF 也可能匯出失敗，改用「下載列印版」再列印即可。其他功能都不受影響。

常見問題

學生可以用手機或平板嗎？

可以。介面會自動調整，手機可以直接拍照上傳。照片會自動壓縮，避免占用太多空間。

學生換電腦怎麼辦？

在原本的電腦下載備份檔，到新電腦打開工具，按「備份與更多 → 從備份還原」並選擇該檔案即可。

出現「儲存失敗：空間可能不足」？

瀏覽器能存的空間有限，通常是照片太多。請先下載備份，再刪掉幾張不必要的照片。

可以改成我們自己的實驗嗎？要不要設定學科？

不用設定。工具沒有綁定學科，數據表的欄位名稱也由學生自己決定，物理、化學、生物、地科的實驗都能用。

按「列印」沒反應？

某些嵌入環境會擋下列印視窗。請改用「匯出 PDF」，或「下載列印版」後在瀏覽器打開再列印。

全組共用一份筆記，還是每人一份？

都可以。共用一份時，建議在「實驗者／組別」寫清楚組員，並固定由一台裝置記錄，避免資料分散在不同裝置上。

自然科學實驗筆記是教學輔助原型，歡迎複製、修改，用在自己的課堂。原始碼與部署說明請見專案的 README。
